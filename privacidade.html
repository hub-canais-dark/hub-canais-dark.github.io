Política de Privacidade

Última atualização: 16 de novembro de 2026

Esta política explica como o aplicativo Hub Canais Dark ("aplicativo") trata os dados das contas Google e YouTube que o autorizam. O aplicativo é usado apenas pela equipe do projeto, nos canais que ela administra.

Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao autorizá-lo, você também concorda com os Termos de Serviço do YouTube. Os dados tratados pelo Google seguem a Política de Privacidade do Google.

Dados acessados

  • Dados do canal: nome, identificador e lista de vídeos do canal autorizado.
  • Envio de vídeos: permissão para enviar, editar título, descrição, miniatura e agendamento de vídeos do próprio canal.
  • Métricas: relatórios do YouTube Analytics do canal autorizado (visualizações, tempo de exibição, retenção, inscritos).
  • Dados públicos: informações públicas de vídeos e canais, obtidas pela API para pesquisa de tendências.

O aplicativo não acessa e-mails, contatos, arquivos ou qualquer outro dado da conta Google além dos listados acima.

Como os dados são usados

Os dados servem exclusivamente para publicar vídeos nos canais do projeto e medir o desempenho deles. Eles não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto quando a lei exigir.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento e segurança

Os tokens de autorização e as métricas ficam armazenados localmente, no computador da equipe que opera o aplicativo, com acesso restrito. Nenhum dado é armazenado em servidores públicos.

Retenção e exclusão

  • Dados de métricas são mantidos enquanto o canal fizer parte do projeto e excluídos em até 30 dias após a saída do canal ou um pedido de exclusão.
  • Dados obtidos pela API do YouTube são atualizados ou excluídos dentro dos prazos exigidos pelas políticas do YouTube.
  • Você pode revogar o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions. Após a revogação, os tokens deixam de funcionar e são apagados.

Cookies

Este site não usa cookies nem ferramentas de rastreamento.

Contato

Dúvidas ou pedidos de exclusão: abra uma solicitação em github.com/hub-canais-dark/hub-canais-dark.github.io/issues.
